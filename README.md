## ℹ️ О проекте

**Geniy Idiot** — это викторина с каверзными вопросами, которые требуют не только знаний, но и логического мышления. Проект разработан в учебных целях и демонстрирует:

- ✅ **ООП принципы** и чистую архитектуру
- ✅ **Работу с JSON** (сериализация/десериализация)
- ✅ **Многопоточность** (таймер с CancellationToken)
- ✅ **Разделение логики и UI** (Class Library + Console + WinForms)
- ✅ **Валидацию данных** и обработку исключений
- ✅ **Систему пользователей** (администратор и игрок)

### 🎮 Режимы игры:
- **Консольная версия** — классический текстовый интерфейс
- **WinForms версия** — графический интерфейс с таймером
- **Режим администратора** — добавление/удаление вопросов
